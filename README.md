## Stack

| Layer | Technology |
|---|---|
| Framework | React 18 + TypeScript |
| Styling | Tailwind CSS v3 + CSS variables (light/dark) |
| Animations | Framer Motion |
| Routing | React Router DOM v6 |
| Icons | Lucide React |
| Build | Vite 6 |
| Package Manager | Yarn |

## Features

- **Terminal mode** — interactive CLI easter egg
- **Animated hero** with typewriter effect
- **Projects** — browser-mockup cards with live/GitHub links and category filters
- **Skills** — bento grid overview with per-category proficiency detail view
- **About** — animated stat counters, experience timeline, interest chips
- **Contact** — conversational chat-style multi-step form
- **Character mascot** — walking blue robot with ambient messages, click reactions, sleep/excited states
- **RPS battle system** — a red rival robot appears periodically and challenges the mascot to Rock Paper Scissors; winner takes the spot

## Getting Started

```bash
git clone https://github.com/Sayem98/sayem.me.git
cd sayem.me
yarn
yarn dev
```

Open [http://localhost:5173](http://localhost:5173).

### Build

```bash
yarn build     # production build → dist/
yarn preview   # preview the build locally
```
